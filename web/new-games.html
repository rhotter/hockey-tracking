A concrete failure: repeated scene resets

In the first Pittsburgh interval, the scene-change heuristic resets six times around recording 10:21–10:22. Sampled raw frames show continuous close-view play with blue #96. Seven known same-person reference pairs cross this boundary, but the current linker rejects connections across scene labels. This is a specific weakness to address; it is not proof that removing the resets alone would recover all seven checks.

The footage, reference and settings were retained unchanged. This diagnosis was made after inference.

Protocol, separation and evidence

The two recordings are absent from the prior source registry. They were selected from the official NBHL channel before viewing the footage, using different regions; venues and teams may overlap prior recordings. All four intervals are retained regardless of activity or model outcome.

The existing pipeline uses the unchanged NBHL YOLO checkpoint, detector-supported SAM2 Large, generic OSNet body-region features and Qwen3-VL Embedding 2B joint-image blending. Roboflow BoT-SORT uses its earlier development-selected defaults, with either the same YOLO detections or the existing NBHL RF-DETR checkpoint. Both detectors remain frozen. All methods receive the same scene-reset signals.

The reference was sealed before inference. Near-in-time continuity supports some identity groups; uncertain longer-gap identity remains unknown. These labels still need independent human review. No time on floor, distance, shots or possession is validated by this test.
