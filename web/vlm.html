Revised-prompt results · Prompt and protocol

What was compared

The image models evaluate a shortlist based on appearance and possible motion, including every originally accepted link. Each proposed direct link spans at most 20 seconds of video between fragments. Long bench absences and full-game roster identity are outside this experiment.

Single-image comparison uses the best crop from each fragment. Multiple-image comparison uses up to three crops from each fragment, spread over time. The reversed-order check asks the same question with the groups swapped. Jersey agreement requires at least two matching complete readings and no conflicting reading within a fragment.

A veto removes a proposed match when the model says the players differ. Strict matching requires positive visual evidence; symmetric matching requires agreement in both group orders. A hybrid combines visual support with the existing appearance score. All methods use the same global link assignment and preserve every input observation and missing interval. Removing one candidate can change competing assignments elsewhere; a veto does not guarantee fewer wrong links. The veto policies retain unqueried candidates.

These are prompting experiments, with no additional model fine-tuning. The original number parser and a separate control that accepts unambiguous decimal strings are both shown.

Runtime, reproducibility and limits

Prompts, candidate selection and policies were frozen before scoring. A documented number-format amendment was sealed after inspecting response formatting but before viewing accuracy results. The method was selected on Massachusetts / Great Britain, using recovered links minus ten times wrong links, then fewer unverified links. The unchanged baseline wins ties.

Pittsburgh and Maryland had been evaluated in earlier experiments. They are regression checks, not a fresh untouched test. Inference ran in parallel; the development choice was sealed before their scores were inspected. The website does not use these fragment IDs to claim player time on floor or distance run.
