SAM 3.1 follow-up

The newer Object Multiplex checkpoint was tested with the same “person” prompt and 0.5 output threshold, with 64 object slots, 16 objects per memory bucket, and compilation disabled. This follow-up was specified after the original SAM3 regression results were known; there was no new prompt sweep.

Official SAM 3.1 release notes. This run measures identity behavior; it is not an optimized speed benchmark. Replay inspection found several boxes spanning much of the rink. The current box-overlap score penalizes that localization failure as well as broken identities.

The one-minute development clip reached the 64-object limit. A separate 128-slot follow-up scored 4/11 correct with 0 wrong joins and 29/35 matched observations. It is not mixed into the original development total. No capacity limit was reached in the four regression clips.

SAM 3.1 mask cleanup experiment

Motivated by the oversized boxes seen in regression replays, then compared on both development clips with 64 object slots. No weights or identities changed. “Final mask” recomputes the box after the model’s overlap suppression. “Largest component” keeps only the largest 8-connected region before deriving the box. Original boxes were rescored from the same inference run for a paired comparison.

Final-mask boxes matched 66/79 observations versus 63/79 originally, with no extra correct connection. Largest-component boxes matched 73/79 and added four correct connections, but also one wrong join. Neither improved the predeclared correct − 10 × wrong objective, so no cleanup variant was promoted to regression testing.

SAM 3D Body

DINOv3 checkpoint: 48 existing player boxes at six fixed frames, processed in 13.6 seconds excluding model loading. It produced ankle positions for all 34 visible-foot, seven occluded-foot, and seven unclear cases. RTMW also emitted on all 48 in the earlier audit. More outputs do not establish higher accuracy.

Raw crop on the left, pose overlay on the right. Cyan: knees; red: ankles. All 48 boxes are shown, including failures. The labels describe visibility only; exact ankle coordinates and ground contact have not been annotated.
